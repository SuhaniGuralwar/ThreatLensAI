# 🛡 ThreatLens AI

ThreatLens AI is a web-based phishing email detection application that helps users identify suspicious emails by analyzing phishing keywords and malicious links. It calculates a risk score and provides security recommendations through a simple and interactive dashboard.

---

## 🚀 Features

- 📧 Email Phishing Detection
- 🔍 Suspicious Keyword Detection
- 🔗 Suspicious Link Detection
- 📊 Risk Score Calculation
- 🟢 Low / 🟡 Medium / 🔴 High Risk Classification
- 📈 Live Dashboard Counters
- 💡 Security Recommendations
- 🧹 Clear Button
- 🎨 Responsive Cybersecurity UI
